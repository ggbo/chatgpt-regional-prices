# Data contract v1

Tax selection chooses an observed amount variant without rewriting source evidence. `all` prefers a current explicitly inclusive amount for each region, falling back to a current exclusive amount; strict inclusive/exclusive modes choose only a matching variant. Both `display_price` and a verified `psp_override` are eligible. A retained or invalid override never borrows the primary amount's verification time. Prices are never synthesized by applying tax rates. The selected amount drives original-price display, conversion, sorting, the minimum card and CSV together; details identify its original field. Conversion uses the same real FX snapshot with decimal precision, and missing FX remains null. The default tax filter stays inclusive.

All money and rates are positive decimal strings. UTC times use RFC3339. Schema version is `1.0.0`. The catalog is versioned; counts are computed from it, never used as a fixed coverage target. Initial catalog: 249 ISO entries, XK, and two auxiliary targets EU/US2.

`config/regions.json`: `{schema_version,catalog_version,regions:[{target_id,country_code,config_id,name_zh,name_en,region_kind,is_country_directory,ranking_eligible,supported_status,supported_checked_at,source_url,discovered_from}]}`. EU/US2 have null country_code and false ranking/directory flags. Support is independent: supported/unsupported/unknown.

`config/plans.json`: `{schema_version,plans:[{plan_id,label,source_plan_key,billing_interval}]}`. Mappings: go→go, plus→plus, pro_100→prolite, pro_200→pro, pro_500→promax. Month only.

`latest.json`: `{schema_version,data_snapshot_id,generated_at,catalog_version,fx_snapshot_id,collector_version,quotes:[]}`. Quotes have record_id/target_id/country_code/config_id/region_kind/channel/plan_id/source_plan_key/billing_interval/offer_type/currency; display_price and optional psp_override; psp_override_status; tax_percent/minor_unit_exponent; availability; source; estimates; last_attempt_at/last_success_at/price_changed_at; issues.

ID: `${config_id}:web:${plan_id}:month:standard`. Price variant: `{amount,tax,source_tax_value,json_pointer,last_success_at,price_changed_at}`. Tax: inclusive/exclusive/unknown. Availability: `{configuration_present,purchase_verified:false,pricing_rollout_gate}`. Source: `{kind:'official_web_config',url,body_sha256,collector_version}`. Estimates: `{USD:{amount,fx_snapshot_id}|null,CNY:{amount,fx_snapshot_id}|null}`. Per-variant timestamps, values and source evidence must be preserved independently. PSP statuses valid/not_present/invalid/stale. Unknown metadata retained in source_metadata with issues.

`coverage.json`: `{schema_version,data_snapshot_id,generated_at,catalog_version,summary,cells:[]}`. Each catalog target has exactly five cells, including auxiliary targets. Cell: `{cell_id,target_id,country_code,config_id,region_kind,plan_id,channel:'web',billing_interval:'month',offer_type:'standard',status,attempt_status,quote_record_id,last_attempt_at,last_success_at,http_status,reason}`. Status: valid_quote/stale_quote/plan_field_missing/request_failed/access_blocked/country_mismatch/amount_invalid/period_unverified/unverified_range/not_attempted. Retained quote has status stale_quote, attempt_status actual failure and original success time. Valid and stale cells reference exactly one quote. Summary: target_count,country_target_count,auxiliary_target_count,expected_request_count,attempted_request_count,not_attempted_request_count,successful_response_count,expected_cell_count,status_counts,current_quote_cell_count,historical_quote_cell_count,complete_five_plan_target_count. Derive all counts.

`fx.json`: `{schema_version,fx_snapshot_id,generated_at,fetched_at,base:'USD',stale,source,rates:[{quote,rate,rate_date,providers:[]}]}`. One coherent source response. USD explicitly 1; missing rates do not default to 1. Failed refresh retains entire old set with stale=true. No prior FX means fx_snapshot_id=null and rates=[]. Provider objects preserve source fields. Estimate local/R[local], then ×R[CNY], Decimal precision 50.

`manifest.json`: `{schema_version,data_snapshot_id,generated_at,catalog_version,fx_snapshot_id,entrypoints:{latest,coverage,fx,reference_comparison,regions,plans},files:[{path,sha256,bytes,media_type}]}`. Entrypoints reference versioned filenames; manifest excluded from its own file list. Client validates IDs and atomically replaces all loaded data. Paths relative and traversal-free.

Publication: full initial catalog attempted, no unexplained not_attempted, at least one current quote. All-source or structural failure never replaces public/data or persisted state. Candidate diagnostics still saved. After baseline, partial errors retain only affected old variants. Price_changed_at changes only for accepted local price/tax/currency changes. No synthetic values or default-US fallback.

Frontend: lowest/highest and ranking use fresh valid quotes, eligible countries and non-null estimates under active filters. Failure, history, auxiliary targets remain searchable. Unknown tax excluded from strict filters. Nulls last both directions, ties by target_id then record_id. All views, summary and CSV share selection logic. Browser clock makes quotes historical after 72h even without another build.

Display scope is official web direct purchase only. Default tax filter is inclusive, default conversion CNY. Inclusive requires an explicitly inclusive verified amount variant as described above; no automatic tax calculation is performed. Nonmatching or missing catalog entries remain searchable with explicit missing-match labels. Original price uses the ISO currency code alongside the amount. Store rows and links are not exposed in the pricing UI or public coverage comparison.

Acquisition policy: config/collection-policy.json defines the revision, 72h attempt window, 48h nominal cycle, concurrency=1 and minimum 2s request spacing (including retries). Missing state or an unknown revision bootstraps the full catalog; declared compatible revisions migrate original observation times and completed bootstrap. At minute23, rotate ceil(N/48) oldest healthy targets first, then due failures. At minute53, request only failed/incomplete targets due after 30 minutes. Success means all five monthly target fields were accepted; only then leave the retry queue. A failed normal rotation joins this same 30m queue.

Initial fill is distinct: capture a durable cohort of initially missing targets, retry them immediately, and persist initial_fill_attempts per target for audit only. There is no attempt-count limit. Success sets initial_fill_done and permanently leaves immediate fill; later failures return only to the 30m queue. Resumed observations and not_attempted targets do not increment counters. Imported actual multi-pass checkpoint counts never decrease existing counters. Targets previously stopped by the retired ten-attempt policy become eligible again if still pending. Each job has a 1500-second budget and explicitly dispatches the next fill workflow only after attempt state is persisted; no eligible targets means no continuation. Healthy targets outside the initial cohort cannot enter this loop. Collector input order is preserved so a time budget cannot repeatedly starve alphabetically later targets.

Failed requests update the attempt ledger, never successful-price timestamps. collection/ledger.json and collection/last-run.json persist even if all selected sources fail or a later check fails. No valid price state is replaced on the all-source-failure branch. A retry with no due targets reuses data without fetching prices or FX. Window metrics distinguish attempted targets from targets with all five accepted prices within 72h; no upstream success guarantee is implied. Partial network failures retain only affected records; structural coverage-drop checks compare previously valid selected cells on successfully parsed responses. JSON generated by the pipeline uses LF on every operating system; official response evidence keeps its exact original bytes.

Ownership: collector scripts/pricing.py, collect.py, fx.py and collector tests; frontend src/**, package files, vite/TS configuration and TS tests; root integration config/**, schemas/**, pipeline/workflow, reference reconciliation, docs, packaging, remote actions. No agents commit or publish.
